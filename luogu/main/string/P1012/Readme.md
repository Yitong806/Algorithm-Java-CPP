# Explanation to P1012 in Luogu
### 拼数最大化
难度：普及-   
要求：给定n个正整数a1, a2, ..., an，将他们前后进行首位数字连接，组成一个很大的数字。询问这个最大的数字是多少。    
做法：按照贪心策略对输入的数字字符串进行排序，其中排序的规则是：    
1. l1和l2进行排序时，先逐位比较其中数字至较短序列结束，如果期间有不一样的数字，则将大的数字尽可能往前放，就排完了；    
2. 如果比较至较短序列结束都不能比较出来，那么就截取较长序列的后续子串再与短序列递归调用排序方法即可。    
3. 总体原则是：数位大的字符串尽可能往前面放，从而使得字符串结果最大化。    
     
示例1：747345 747比较    
前3位均为747，那么就将345与747比较，因此747就排在747345前面。      
示例2：747996 747比较    
前3位均为747，那么就将996与747比较，因此747996就排在747前面。
