# Explanation to Tree Problems in Luogu

### P1030 中序后序求前序
难度：普及-   
要求：给定一棵树的中序遍历（左中右）和后序遍历（左右中），要求输出该树的前序遍历（中左右）。由于提供了中序遍历，因此题目可以保证树的结构唯一。  
做法：  
1. 从后序遍历入手，对于给定后序遍历序列，最后一位对应的一定是根节点；  
2. 然后去中序遍历序列里去寻找该根节点的位置；  
3. 接下来继续考虑中序遍历，以该根节点左右划分为左子树和右子树进行递归构造（后序遍历需要根据子树序列长度来进行左右划分）  
4. 最后递归返回结果即可。  
    
示例：   
中序：BADC，后序：BDCA   
1. 先考虑后序遍历，得到根节点是A；
2. 然后在中序遍历中以A为分界线进行左右划分，得到左子树是B，右子树是DC；
3. 由于B子树只有一节点，因此递归结束；对于DC子树，回到步骤1可以得到右子树根节点是C，而C的左子树是D。

难点：序列长度等数值的计算关系要严格考虑，如果任何地方的计算出现一点点闪失都会导致各种RE或者WA。
