# Explanation to P1007 in Luogu
难度：普及-   
要求：   
一座L长度的独木桥上有n个士兵，移动规则如下：    
1. 这n个士兵初始时既可以向左走，也可以向右走；   
2. 其中如果两个士兵碰面，则两人都反向移动；   
3. 在同一时间多名士兵可以重叠在同一个位置；      
4. 当一个士兵的位置脱离了区间[1,L]，则视为该士兵已经成功下桥。   
现给定这n个士兵的起始位置，询问这n个士兵全部下桥所需的最短时间和最长时间分别是多少。    
    
做法：   
1. 首先，本题无论求最大值还是最小值，总时间T的定义一定是T=max(t[i]), i = 1,2,3,...,n, 其中t[i]为第i个士兵下桥所需要的时间。    
2. “两士兵碰面”其实可以换一种理解方式，即为两个人换个编号，然后从对方身体里直接穿了过去，因为转身无需时间，那么也就是说每个士兵的运行是独立的，与其他士兵无关；   
3. 根据2，以及初始朝向是不确定的，我们就可以知道t[i]有可能有两个值，place[i]和L+1-place[i]。
4. 根据贪心的策略，我们就可以得到需要的两个答案了。
