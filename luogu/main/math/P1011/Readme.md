# Explanation to P1011 in Luogu
### 车站
难度：普及-   
要求：有这样一辆列车：   
1. 列车从首发站（第1站）发车，在首发站上车*a*人；   
2. 在第2站中，上车下车人数相等，但具体数值未知；   
3. 从第3站开始，运行到终点站的前1站（第(*n-1*)站），都符合上车人数=前2站上车人数之和，下车人数=前1站上车人数；   
4. 最后一站（第*n*站）所有人下车，其下车人数为*m*。   
给定*n*，*a*，*m*的具体数值，然后处理一个询问，对于给定的数值*x*，询问列车从第*x*站开出时，列车上有多少人？
    
做法：   
本题最大的疑点和突破口在于第2站上下车的人数未知，导致不能继续递推。因此我们可以设该站上下车的人数都是*y*。    
先定义一个类，用于保存关于*y*的一元一次式子的常数和*y*的系数，然后根据*a*常量进行初始化打表，可以得到*m*与未知量*y*的一次关系式。     
最后根据*n*找到指定的多项式，反向求出未知量*y*，最后输出指定位置的车辆人数即可。
